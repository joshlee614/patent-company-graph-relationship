# PCP TMS - 수요기업 매칭 대시보드 (Frontend)

이 레포지토리는 KIPRIS 특허 인용 데이터를 기반으로 대학 보유 기술과 수요 기업 간의 수요 점수(Demand Score)를 평가하고 추천하는 시각화 대시보드의 **프론트엔드 파트**입니다.

## 🚀 배포 정보

이 사이트는 **GitHub Pages**를 통해 자동으로 호스팅됩니다. `.github/workflows/deploy.yml` 액션을 통해 `main` 브랜치에 푸시되는 즉시 `frontend/` 폴더의 내용이 배포됩니다.

## 💡 주요 기능
- **특허 인용 그래프**: `vis.js` 네트워크 라이브러리를 활용하여, 13대 전략기술에 맞춘 시각적 컬러 코딩 및 인용 간선 시각화 제공.
- **Actionable CRM 대시보드**: 클릭한 기업(노드)의 추천 이유, AI 타겟팅 기술 교집합 파이프라인, 협상 상태 파악을 한 화면에서 지원.
- **AI 프롬프트 생성기**: 메일 초안, 분석 보고서 등 후속 액션을 AI(LLM)에 요청할 수 있는 최적화된 하이퍼 리얼 프롬프트가 동적 생성됨.

## 🛠 아키텍처 (백엔드 분리)
해당 레포지토리는 보안 및 용량 상의 이유로 수백 MB에 달하는 37만 건의 `tblTechAllNew` 특허 백데이터(`*.csv`)와 처리 백엔드 소스코드를 포함하지 않습니다.

현재 데이터를 연동하기 위해 두 가지 방식 중 하나를 사용할 수 있습니다:
1. `app.js` 최상단의 `API_BASE_URL` 값을 별도 Application에서 구동 중인 데이터 API 서버 또는 AWS S3 등 외부 스토리지 링크로 변경.
2. (로컬 검증용) 로컬 서버로 사용할 땐 `API_BASE_URL`을 `.` 혹은 빈 문자열로 둔 후, `output_edges.csv`, `output_demand_scores.csv` 파일을 `frontend` 폴더에 위치시킨 채 서버를 기동.
